# Security

Never commit an OpenAI API key, authorization header, cookie, billing export or
account identifier. Run the benchmark with a restricted, temporary key passed
only at execution time. Revoke it after the public package and article pass QA.

If you find a credential or personal datum in a release, do not quote it in a
public issue. Contact the repository owner privately through the contact method
published by chatgpt-gratis.chat, then rotate the affected credential.
